# Fraud Detection in Banking

## Project Overview
This project uses Machine Learning techniques to detect fraudulent banking transactions. The model is trained on a credit card transaction dataset and classifies transactions as either legitimate or fraudulent.

## Objectives
- Analyze banking transaction data
- Identify fraudulent transactions
- Visualize transaction patterns
- Build a Machine Learning classification model
- Evaluate model performance

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-Learn
- Jupyter Notebook

## Features
- Data Cleaning and Analysis
- Fraud vs Normal Transaction Visualization
- Transaction Amount Distribution Analysis
- Machine Learning Model Training
- Fraud Prediction
- Model Evaluation

## Dataset
Credit Card Fraud Detection Dataset

Dataset Source:
https://www.kaggle.com/datasets/mlg-ulb/creditcardfraud

## Project Outputs
- Fraud vs Normal Transactions Graph
- Transaction Amount Distribution Graph
- Fraud Prediction Model
- Accuracy Score
- Classification Report

## Machine Learning Algorithm
- Logistic Regression

## How to Run

1. Install required libraries

pip install pandas numpy matplotlib scikit-learn jupyter

2. Open Jupyter Notebook

3. Run fraud_detection.ipynb
